# CraveFit

CraveFit is a static, client-side HTML app. The public site contains no backend code or server credentials.

## Share the app

After GitHub Pages is enabled and the Pages workflow completes, share:

https://cravefit-diet.github.io/CraveFit/

The lowercase `index.html` entry point automatically opens the existing dashboard.

## Privacy and security

This repository currently contains only frontend code. Anything placed in HTML or browser JavaScript is public to visitors. Do not put API keys, passwords, database credentials, or private business logic in this repository. A real backend must be deployed separately as a server/API and protected with authentication.
